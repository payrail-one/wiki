# Payrail Wiki

This repository is the Git-tracked Payrail developer wiki. Start at
[Home](Home.md) or use the [_Sidebar](_Sidebar.md) navigation.

The canonical public documentation repository is
[payrail-one/docs](https://github.com/payrail-one/docs). Development assets are
test-only, and the current public finality mode is not production BFT finality.
